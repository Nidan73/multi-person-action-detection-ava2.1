ROI ALIGN
Use torchvision.ops.roi_align.

For each temporal position t:
spatial_feat = feat[:, :, t, :, :] → (B, C_feat, H_feat, W_feat)

text

boxes are normalized [0,1]. Scale to feature map coords:
    x1_abs = x1 * W_feat
    y1_abs = y1 * H_feat
    x2_abs = x2 * W_feat
    y2_abs = y2 * H_feat

Format for roi_align: list of (N_i, 4) tensors per batch item,
or use (K, 5) format with [batch_idx, x1, y1, x2, y2].

Since batch_size = B and each sample has exactly 1 actor:
    roi_boxes = torch.cat([batch_indices, scaled_boxes], dim=1)
    where batch_indices = torch.arange(B).unsqueeze(1)

roi_out = roi_align(spatial_feat, roi_boxes, output_size=roi_size,
                    spatial_scale=1.0)
→ (B, C_feat, roi_size, roi_size)

GEOMETRY ENCODER
Compute from boxes:
width = x2 - x1
height = y2 - y1
area = width * height
cx = (x1 + x2) / 2
cy = (y1 + y2) / 2
aspect = width / (height + 1e-6)
→ (B, T, 6) or (B, 6) for center-only

baseline1 geometry:

geo_gate = sigmoid(geo_feat)
actor_feat = actor_feat * geo_gate
